📋 QUICK START GUIDE
═══════════════════

✅ STEP 1: Open Terminal/Command Prompt

   Windows: Press Win+R, type "cmd", press Enter
   Mac: Press Cmd+Space, type "terminal", press Enter

✅ STEP 2: Navigate to Project Folder

   cd C:\Users\Asus\Desktop\xylofy\HousePricePrediction_SmartAI

✅ STEP 3: Install Dependencies (First Time Only)

   npm install

   ⏱️ Takes 2-3 minutes

✅ STEP 4: Start the Application

   npm start

   🎉 App opens automatically at http://localhost:3000

🛠️ TROUBLESHOOTING
═══════════════════

Problem: npm install fails
Solution: npm cache clean --force && npm install

Problem: Port 3000 in use
Solution: Use different port: set PORT=3001 && npm start

Problem: CSV not found
Solution: copy ..\Housing.csv public\Housing.csv

Need more help? Check SETUP_GUIDE.md!
